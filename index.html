Format Centang (✓)

1 baris = 1 pokok. Tiap karakteristik dipecah jadi beberapa kolom sesuai pilihannya, dan yang terpilih ditandai ✓ (mirip file excel aslimu).

Format Teks (penamaan langsung)

1 baris = 1 pokok, 1 kolom per karakteristik — isinya langsung nama pilihan yang dipilih (bukan tanda centang). Lebih ringkas & gampang dianalisis.

Cara pakai di Android

Buka file HTML ini pakai Chrome di HP Android, lalu ketuk menu (⋮) → "Tambahkan ke layar Utama" supaya muncul ikon seperti aplikasi. Semua data disimpan langsung di browser HP ini (tidak perlu internet), jadi bisa dipakai di lapangan tanpa sinyal. Setelah selesai input, buka tab Export untuk mengunduh hasilnya sebagai Excel/CSV — bisa coba dua format di atas untuk dibandingkan.

⚠️ Data tersimpan per-HP dan per-browser — kalau ganti HP atau hapus data browser, export dulu datanya. Disarankan export rutin sebagai backup.
